Custom Preset Manager

커스텀 프리셋 매니저

프리셋 안의 프롬프트를 입력창 위에서 바로 켜고 끄는 확장입니다. 프롬프트 매니저를 열지 않고 조합을 바꾸고, 상황에 따라 알아서 켜지도록 만들 수도 있습니다.

기능 보기 ↓ 설치 방법

01 처음이라면 이 세 가지

설정에 항목이 많지만 처음부터 전부 켤 필요는 없습니다. 아래 세 가지면 충분합니다.

프롬프트 하나 켜고 끄자고 매번 프롬프트 매니저를 열게 됩니다.

빠른 프롬프트 토글

자주 쓰는 프롬프트에 토글 버튼을 달아 입력창 바로 위에 놓습니다. 채팅을 이어가면서 그 자리에서 켜고 끌 수 있습니다.

켜는 곳설정 → 빠른 프롬프트 토글 표시

지금 켜둔 조합이 실제로 어떤 프롬프트로 조립되는지 확인할 방법이 없습니다.

프롬프트 미리보기

실제로 전송될 프롬프트를 순서대로 카드에 펼쳐 보여줍니다. 무엇이 어디에 들어갔는지 보낸 뒤에 짐작하지 않아도 됩니다.

켜는 곳설정 → 프롬프트 미리보기 표시

다른 프리셋에 있는 좋은 프롬프트를 지금 프리셋으로 가져오고 싶습니다.

프리셋 커스텀 패널

가지고 있는 모든 프리셋의 프롬프트를 목록으로 펼쳐 봅니다. 내용을 복사하거나, 지금 쓰는 프리셋에 그대로 추가할 수 있습니다.

켜는 곳설정 → 프리셋 커스텀하기 버튼 표시

설정은 어디에 있나요? 실리태번 확장 메뉴(퍼즐 조각 아이콘) → Custom Preset Manager 를 펼치면 아래 기능들을 하나씩 켜고 끌 수 있습니다.

기능을 끄면 관련된 버튼과 메뉴가 화면에서 사라질 뿐, 저장해둔 설정은 지워지지 않습니다. 부담 없이 켜보고 맞지 않으면 다시 끄면 됩니다.

02 이런 게 필요해지면

쓰다 보면 하나씩 아쉬워지는 것들입니다. 해당되는 것만 켜세요.

매번 같이 켜고 같이 끄는 프롬프트가 여러 개 있습니다.

토글 그룹

여러 프롬프트를 버튼 하나로 묶습니다. 그룹 버튼을 누르면 묶인 프롬프트가 한꺼번에 켜지고 꺼집니다.

켜는 곳설정 → 토글 그룹 기능

조합만 다른 프리셋을 여러 개 만들어 두고 오갑니다.

토글 프리셋

켜둔 조합에 이름을 붙여 저장해두고, 드롭다운에서 골라 바꿉니다. 프리셋 하나 안에서 조합만 갈아끼우기 때문에, 프롬프트를 손볼 일이 생겨도 한 곳만 고치면 됩니다.

켜는 곳설정 → 토글 프리셋 표시

채팅방마다 쓰는 프리셋이 다릅니다.

연결 프리셋

채팅방마다 쓸 프리셋을 지정해두면, 그 방에 들어갈 때 자동으로 전환됩니다.

켜는 곳설정 → 연결 프리셋 표시

특정 내용이 나올 때만 필요한 프롬프트를, 매번 직접 켜고 끄고 있습니다.

프롬프트 키워드 트리거

최근 대화에 지정한 키워드가 있을 때만 프롬프트를 넣습니다. 로어북과 같은 방식이라 /정규식/ 도 쓸 수 있고, 뒤에서 몇 개의 메시지까지 검사할지 프롬프트마다 따로 정할 수 있습니다.

켜는 곳설정 → 프롬프트 키워드 트리거 · 프롬프트 편집의 Triggers 목록에 키워드가 추가됩니다

프롬프트 순서를 바꾸려면 목록에서 끌어다 옮겨야 합니다.

프롬프트 위치 정하기

위치를 목록에서 골라 정합니다. 추가할 때도, 나중에 바꿀 때도 끌어다 옮기지 않아도 됩니다.

켜는 곳설정 → 프롬프트 위치 정하기

채팅에 나온 문장을 프롬프트로 옮겨두고 싶습니다.

채팅에서 프롬프트 담기

메시지의 코드블럭이나 드래그한 텍스트를 그 자리에서 프리셋 프롬프트로 저장합니다.

켜는 곳설정 → 채팅에서 프롬프트 담기

받아온 프리셋이 영어라, 각 프롬프트가 무슨 내용인지 알기 어렵습니다.

프롬프트 번역

프롬프트 편집기의 번역 버튼으로 내용을 번역해 봅니다. 번역에 쓸 연결 프로필과 번역 지시문을 직접 정할 수 있고, 한 번 번역한 내용은 저장돼서 다시 볼 때 또 번역하지 않습니다.

켜는 곳설정 → 번역 기능 사용 · 쓰기 전에 번역 프로필을 하나 골라두세요

03 켜두면 편한 것들

화면을 바꾸지는 않지만, 켜두면 손이 덜 가는 설정입니다.

프리셋 자동 저장 프롬프트를 수정해 저장하면 프리셋까지 함께 저장합니다. 저장을 잊어 작업이 날아가는 일이 없어집니다.
프롬프트 자동 연결 새로 만든 프롬프트를 목록에 자동으로 연결합니다. 만들었는데 어디에도 안 보이는 상황을 막아줍니다.
빠른 토글 접기 토글 버튼이 늘어나면 입력창 위가 좁아집니다. 평소에는 접어두고 필요할 때만 펼칩니다.

04 설치

실리태번 안에서 Git URL로 바로 설치합니다.

  1. 실리태번 상단의 확장 메뉴(퍼즐 조각 아이콘)를 엽니다.
  2. Install extension 버튼을 누릅니다.
  3. 아래 주소를 붙여넣고 설치합니다.
  4. 설치가 끝나면 새로고침(F5) 합니다.
https://github.com/keepsanity/SillyTavern-CustomPreset
