TMI Generator

TMI 생성기

답장을 받을 때마다 캐릭터의 습관이나 숨은 생각, 세계관 뒷설정 같은 TMI를 만들어 메시지 아래에 붙여줍니다. 프롬프트와 CSS를 직접 고쳐서 원하는 내용, 원하는 모양으로 바꿀 수 있어요.

사용법 보기 ↓ 설치 방법

01 사용법

설치하면 바로 동작합니다. 설정은 나중에 천천히 바꿔도 돼요.

  1. 설치하면 확장 메뉴에 TMI Generator Settings가 생깁니다.
  2. 채팅 메시지의 … 메뉴에 있는 말풍선 아이콘(TMI 생성)을 누르면 그 메시지 아래에 TMI 박스가 생깁니다. 설정에서 AI 답장 시 자동으로 TMI 생성을 켜두면 답장을 받을 때마다 알아서 만들어집니다.
  3. 박스는 접혀 있으니 눌러서 펼치세요.
  4. 마음에 안 들면 🔄 로 다시 만들고, 필요 없으면 ❌ 로 지웁니다.

02 탭과 핀

같은 메시지에 다른 종류의 TMI도 받아보고 싶습니다.

탭

처음에는 설정에서 고른 프롬프트로 생성됩니다. TMI 박스의 + 를 눌러 다른 프리셋을 고르면 새 탭으로 추가 생성됩니다. 재생성과 삭제 버튼은 탭마다 붙고, 일괄 재생성 · 일괄 삭제는 없습니다.

찾는 곳TMI 박스 위쪽 탭 줄 → +

마음에 든 TMI를 앞으로의 대화에도 반영하고 싶습니다.

핀

TMI 항목에 마우스를 올리면 나오는 📌 를 누르면, 그 항목이 작가 노트처럼 매 요청에 함께 들어갑니다. 해제하려고 그 메시지까지 스크롤해서 올라갈 필요 없이, 마법봉 메뉴의 TMI 관리에서 핀 목록을 보고 바로 해제할 수 있습니다.

관리마법봉 메뉴 → TMI 관리 · 넣는 위치와 방식은 설정 → 핀한 TMI를 프롬프트에 주입

03 설정

확장 메뉴 → TMI Generator Settings

Extension 활성화 확장을 켜고 끕니다.
Generation Source TMI를 만들 API를 고릅니다. Main API를 써도 되고, 다른 모델로 만들고 싶다면 연결 프로필을 만들어 연결하면 됩니다.
AI 답장 시 자동으로 TMI 생성 켜두면 답장을 받을 때마다 자동으로 만듭니다. 끄면 메시지의 TMI 생성 버튼으로 직접 만듭니다.
생성된 TMI를 자동으로 펼쳐서 표시 TMI 박스는 원래 접혀 있습니다. 켜면 펼친 상태로 보여줍니다.
TMI 개수 한 번에 몇 개를 만들지 정합니다. 10개까지 가능해요.
TMI 항목당 길이 1~2줄짜리 짧은 TMI부터 7줄 이상의 긴 TMI까지 고릅니다.
TMI 출력 언어 English로 두면 영어로, 한국어로 두면 한국어로 나옵니다.
최대 응답 토큰 수 연결 프로필로 만들 때만 적용됩니다(기본 4000). Main API는 지금 프리셋의 응답 길이를 따릅니다.
컨텍스트 메시지 수 최근 채팅을 몇 개까지 참고할지 정합니다.
이미 나온 TMI 반복 방지 앞서 나온 TMI와 핀한 항목을 빼고 만들게 합니다.
커스텀 프롬프트 어떤 TMI를 볼지 여기서 자유롭게 고칩니다. 기본 제공 프리셋 중에 고를 수 있고, 고친 프롬프트는 내 프리셋으로 저장해둘 수 있어요.
Custom CSS TMI 박스 모양을 고칩니다. 원하는 디자인, 원하는 테마에 맞게 바꿀 수 있고 CSS도 프리셋으로 저장해둘 수 있어요.
TMI 데이터 관리 TMI가 너무 쌓여서 느려진 것 같거나 다 지우고 싶을 때, 현재 채팅방 TMI 초기화로 비웁니다.

실리태번 안에서 Git URL로 바로 설치합니다.

  1. 실리태번 상단의 확장 메뉴(퍼즐 조각 아이콘)를 엽니다.
  2. Install extension 버튼을 누릅니다.
  3. 아래 주소를 붙여넣고 설치합니다.
  4. 설치가 끝나면 새로고침(F5) 합니다.
