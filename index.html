03 설치 & 사용법

처음이라면 여기부터 보세요.

🧩 확장(익스텐션) 설치

  1. 실리태번 상단의 확장 메뉴(퍼즐 조각 아이콘)를 엽니다.
  2. Install extension 버튼을 누릅니다.
  3. 아래 Git URL을 붙여넣고 설치합니다. (각 카드의 Git URL 복사 버튼으로 복사할 수 있어요)
  4. 설치 후 새로고침(F5) 하면 적용됩니다.
https://github.com/keepsanity/SillyTavern-CustomPreset

※ 확장 업데이트는 확장 목록에서 해당 확장의 Update 버튼으로 할 수 있습니다.

🎨 테마 적용

  1. SillyTheme 저장소에서 원하는 .json 파일을 받습니다. (파일을 열고 Download raw file 버튼)
  2. 실리태번 사용자 설정(User Settings) → Themes 로 이동합니다.
  3. Import(가져오기) 버튼으로 받은 JSON을 불러옵니다.
  4. 테마 목록에서 방금 불러온 테마를 선택하면 끝입니다.

※ 기존 테마를 덮어쓰지 않도록, 마음에 드는 설정이 있다면 먼저 내보내기(Export)로 백업해두세요.

🌐 웹 도구 사용

  1. 설치가 필요 없습니다. 링크를 열고 파일을 올리면 바로 동작합니다.
  2. 프리셋 JSON은 실리태번의 프리셋 내보내기로, 로어북 JSON은 worlds 폴더에서 가져오면 됩니다.
  3. 모든 처리는 브라우저 안에서만 이루어집니다. 파일이 서버로 전송되지 않아요.

※ 편집 결과는 새 파일로 저장해서 실리태번에 다시 불러오는 방식입니다.
