Simulation Manager

시뮬레이션 매니저

"만약 이랬다면?" 같은 OOC 요청을 메인 롤플레이와 따로 돌려보는 확장입니다. 시뮬레이션은 채팅에 메시지로 남지 않고, 다음 답장 때 AI에게 보내지지도 않습니다. 채팅방마다 목록으로 쌓아두고, 답변을 여러 개 뽑아 넘겨보며 고를 수 있습니다.

사용법 보기 ↓ 설치 방법

01 처음 한 번 돌려보기

설정을 건드리지 않아도 바로 쓸 수 있습니다. 순서대로 따라 해보세요.

  1. 채팅방에서 입력창 왼쪽의 지팡이 메뉴를 열고 시뮬레이션을 누릅니다.
  2. 새 시뮬레이션을 누르고 내용에 요청을 적습니다. 예: {{char}}가 일기를 쓴다면 오늘 일을 어떻게 적을까?
  3. 시뮬 전송을 누르면 답변이 생성됩니다. 생성 중에는 팝업을 닫아도 되고, 끝나면 알림이 뜹니다.
  4. 마음에 안 들면 재생성을 누르세요. 이전 답변은 지워지지 않고 하나씩 쌓이며, ‹ › 화살표로 넘겨볼 수 있습니다.

※ 생성 중에는 재생성 버튼이 취소로 바뀝니다. 메인 채팅이 답장을 생성하는 동안에는 시뮬 전송이 눌리지 않으니, 끝난 뒤에 보내세요.

시뮬 돌리려면 꼭 깔아야 하나요? 아니요. 시뮬용 채팅방을 따로 파거나, 시뮬을 보낸 뒤 메시지를 hide · 삭제 처리하는 게 번거로워서 만든 확장입니다. 시뮬 답변을 전부 남겨두고 계속 보고 싶을 때, 시뮬용 채팅방을 따로 관리하고 싶지 않을 때 쓰면 좋습니다.

어떤 API로 생성하나요? 시뮬은 좋은 모델로 받고 싶어서 지금 연결된 메인 API를 그대로 씁니다. 프리셋만 따로 고를 수 있고(실행 옵션), 번역과 로어북 요약에만 별도 연결 프로필을 지정할 수 있습니다.

메인 롤플레이에 정말 영향이 없나요? 시뮬레이션은 채팅 파일 안에 따로 저장되고, 채팅 메시지로 추가되지 않습니다. 평소 답장을 받을 때 AI에게 보내지지 않습니다.

반대로 시뮬레이션을 만들 때는 지금 채팅 내용과 캐릭터 카드, 로어북을 평소처럼 읽습니다. 재생성할 때도 그 시점의 채팅을 다시 읽습니다.

시뮬레이션은 채팅방(채팅 파일)마다 따로 저장됩니다. 채팅을 지우면 그 방의 시뮬도 함께 사라지니, 남기고 싶은 건 백업해두세요.

02 답변을 다듬고 싶을 때

답변을 처음부터 다시 뽑지 않고, 이어 쓰거나 일부만 고칠 수 있습니다.

답변이 좋은데 너무 일찍 끝났습니다. 그다음이 궁금합니다.

이어쓰기

원래 요청과 지금까지의 답변을 보고, 반복하거나 고쳐 쓰지 않고 다음 내용만 이어서 씁니다. 이어 쓴 내용은 답변 아래에 새 파트로 붙습니다.

찾는 곳시뮬 상세 화면 아래 → 이어쓰기

이어서 쓰되, 이야기가 내가 원하는 방향으로 흘러갔으면 합니다.

OOC 이어쓰기

"다음엔 비가 쏟아진다"처럼 방향을 적어주면, 분위기가 바뀌더라도 그 방향을 따라 이어 씁니다. 문체는 원래 답변을 그대로 따릅니다. 적은 지시는 화면에 따로 보이지 않고, 마지막에 쓴 지시만 저장돼서 다음에 다시 채워집니다.

찾는 곳시뮬 상세 화면 아래 → OOC (표지판 아이콘)

전체는 괜찮은데 한 부분만 마음에 안 듭니다.

통제광

파트 하나를 골라 "대사를 더 짧게", "존댓말로" 같은 피드백을 적으면, AI가 편집자처럼 그 파트만 고쳐 씁니다. 이야기를 이어가지 않고 길이와 형식도 비슷하게 유지합니다. 고친 결과는 새 답변으로 저장되고, 원래 답변은 ‹ 로 돌아가면 그대로 있습니다. inSTead 확장에서 아이디어를 얻은 기능입니다.

찾는 곳각 파트 옆 아이콘 → 통제광 (마술봉)

AI에게 맡기기보다 직접 몇 글자 고치고 싶습니다.

파트 수정

파트 내용을 직접 고쳐 저장합니다. 통제광과 마찬가지로 원본을 덮어쓰지 않고, 고친 버전이 새 답변으로 추가됩니다.

찾는 곳각 파트 옆 아이콘 → 수정 (연필)

방금 이어 쓴 부분만 다시 뽑고 싶습니다.

이 파트 재생성

마지막으로 이어 쓴 파트만 다시 생성합니다. 이전 버전도 남아서 파트 머리의 작은 ‹ › 로 비교해볼 수 있습니다. 필요 없어진 이어쓰기 파트는 삭제(✕) 로 지웁니다.

찾는 곳마지막 파트 옆 아이콘 → 이 파트 재생성 (↻)

영어로 받은 답변을 한국어로 읽고 싶습니다.

응답 번역

파트마다 번역 버튼이 생깁니다. 한 번 번역한 내용은 시뮬과 함께 저장돼서 번역 / 원문 으로 오가며 볼 수 있고, 마음에 안 들면 재번역 합니다.

켜는 곳설정 → 응답 번역 기능 사용 · 번역에 쓸 Connection Profile을 꼭 골라두세요

답변과 파트는 뭐가 다른가요? 답변은 재생성할 때마다 하나씩 늘어나는 단위로, 응답 위의 ‹ › 와 N / M 으로 넘깁니다.

파트는 한 답변 안의 조각입니다. 처음 생성된 내용이 1번 파트이고, 이어쓰기를 할 때마다 다음 파트가 붙습니다.

03 답변을 활용하고 싶을 때

마음에 든 시뮬은 채팅이나 로어북으로 옮길 수 있습니다.

시뮬 내용이 좋아서, 이걸 시작점으로 새 롤플레이를 하고 싶습니다.

새 챗

지금 보고 있는 답변을 첫 인사말로 삼아 같은 캐릭터와 새 채팅을 엽니다. 응답만을 고르면 답변이 인사말이 되고, 요청 포함을 고르면 내 요청이 유저 메시지로, 답변이 캐릭터 메시지로 들어갑니다.

찾는 곳응답 위 버튼 → 새 챗

시뮬로 써본 장면을 지금 채팅에 그대로 이어 붙이고 싶습니다.

기존 챗

답변을 현재 채팅의 맨 끝에 캐릭터 메시지로 추가합니다. 새 챗과 마찬가지로 요청을 함께 넣을지 고를 수 있습니다. 이 버튼을 눌렀을 때만 시뮬 내용이 실제 채팅에 들어갑니다.

찾는 곳응답 위 버튼 → 기존 챗

시뮬에서 정해진 설정을 앞으로도 기억하게 하고 싶습니다.

로어북 엔트리로 저장

답변을 요약해 로어북 엔트리로 만듭니다. 제목, 키워드, 본문이 미리 채워지니 확인하고 고친 뒤 저장하면 됩니다. 저장할 로어북, 활성화 방식(키워드 · 상시 · 벡터화), 위치와 깊이도 이 창에서 고릅니다. 저장을 누르면 고른 로어북에 그 값 그대로 바로 들어갑니다.

⚠️ 버튼을 누르자마자 요약 요청이 바로 나갑니다. 요약이 마음에 안 들면 다시 요약을 누르세요.

찾는 곳응답 위 버튼 → 로어북 · 기본값과 요약 프롬프트는 설정 → 로어북 엔트리 생성

이 시뮬을 채팅의 어느 시점에서 만들었는지 기억이 안 납니다.

위치 표시 · 이동

답변마다 생성할 때 채팅의 마지막 메시지가 📍 #번호 이름 으로 표시됩니다. 이동을 누르면 채팅이 그 메시지로 스크롤됩니다. 그사이 메시지가 지워졌다면 삭제됨으로 표시됩니다.

찾는 곳시뮬 상세 화면 → 응답 위 📍 줄

채팅에서 받은 답장 하나를 따로 보관해두고 싶습니다.

시뮬로 저장

AI 메시지를 그대로 시뮬 목록에 담습니다. 바로 앞의 내 메시지가 요청으로, 그 답장이 답변으로 들어갑니다. 담은 뒤에는 다른 시뮬처럼 이어쓰기나 재생성도 할 수 있습니다.

찾는 곳AI 메시지의 … 메뉴 → 플라스크 아이콘 (시뮬로 저장)

04 이런 게 필요해지면

쓰다 보면 하나씩 아쉬워지는 것들입니다. 대부분 새 시뮬레이션 화면의 접힌 항목 안에 있습니다.

자주 쓰는 시뮬 요청을 매번 다시 타이핑합니다.

저장된 프롬프트

한 번 보낸 요청은 자동으로 저장돼서, 다음엔 목록에서 골라 바로 채울 수 있습니다. 제목이나 내용으로 검색하고 최신순 · 오래된순 · 이름순으로 정렬합니다. 저장하고 싶지 않은 일회성 요청은 저장 옵션 → 이 프롬프트 저장 안 하기를 체크하세요.

찾는 곳새 시뮬레이션 → 저장된 프롬프트 불러오기 · 이름 바꾸기와 삭제는 설정 → 저장된 프롬프트 관리

시뮬만 다른 프리셋으로 돌리고 싶습니다.

실행 옵션 · 프리셋

시뮬을 생성하는 동안에만 고른 프리셋으로 바꿨다가, 끝나면 원래 프리셋으로 돌아옵니다. Custom Preset Manager의 토글 프리셋을 쓰고 있다면 토글 프리셋도 함께 고를 수 있습니다.

찾는 곳새 시뮬레이션 → 실행 옵션 · 만든 뒤에는 상세 화면의 ⚙ 줄을 눌러 바꿉니다

요청이 대화 속 어디에 들어가는지에 따라 답변이 달라집니다.

주입 위치

잘 모르겠다면 기본값 마지막 메시지 (깊이 0)을 그대로 두세요. 요청이 대화 기록 맨 끝, 최근 메시지 바로 뒤에 들어갑니다. 마지막 메시지 (임시 삽입)은 같은 자리에 요청을 잠깐 진짜 유저 메시지로 넣었다가 뺍니다. 깊이 1은 최근 메시지 바로 앞에, 맨 밑은 대화 기록 바깥, 시스템 프롬프트까지 다 끝난 프롬프트 맨 끝에 넣습니다.

찾는 곳새 시뮬레이션 → 실행 옵션 → 주입 위치 · 기본값은 설정 → 기본 주입 위치

입장을 바꿔서, 캐릭터가 내 입장이 되는 시뮬을 해보고 싶습니다.

변환 옵션

{{char}} ↔ {{user}} 교체는 요청 안의 두 매크로를 서로 바꿉니다. 대명사 교체는 요청 속 영어 대명사(he ↔ she 등)를 바꿉니다. 대신 쓸 단어를 적으면 {{char}} · {{user}} 자리에 원래 이름 대신 그 단어가 들어갑니다.

찾는 곳새 시뮬레이션 → 변환 옵션

같은 시뮬을 여러 캐릭터에게 한꺼번에 돌려보고 싶습니다.

여러 방에 보내기

보낼 캐릭터나 그룹을 체크하고 전송하면, 각 방을 차례로 열어 같은 요청으로 시뮬을 만들고 그 방의 목록에 저장합니다. 끝나면 원래 방으로 돌아옵니다. 진행 상황은 떠 있는 창에 표시되고 중지로 멈출 수 있습니다. 각 캐릭터의 지금 열려 있는 채팅으로 보내집니다.

찾는 곳새 시뮬레이션 → 여러 방에 보내기

시뮬에 실제로 어떤 프롬프트가 보내지는지 확인하고 싶습니다.

전송 전 프롬프트 확인

보내기 직전에 조립이 끝난 프롬프트를 블록별로 펼쳐 보여주고, 전송할지 취소할지 묻습니다. 사용할 프리셋, 주입 위치, 대략의 토큰 수도 함께 보입니다.

켜는 곳설정 → 전송 전 프롬프트 확인

팝업을 열지 않고 명령어나 빠른 답장으로 시뮬을 돌리고 싶습니다.

/sim 명령어

/sim name= 까지 치면 저장된 프롬프트 제목이 자동완성으로 뜨고, /sim name="던전 시뮬" 처럼 실행합니다. 아무 요청이나 바로 던지려면 /sim 만약 지금 비가 왔다면? 처럼 뒤에 내용을 쭉 적으면 됩니다. 백그라운드에서 생성해 지금 방의 시뮬 목록에 저장합니다.

이렇게 바로 적은 즉석 요청은 저장된 프롬프트에 자동 저장되지 않습니다.

옵션preset= 프리셋 (자동완성) · position= 요청 넣을 위치 depth_0 / temp_message / depth_1 / bottom · quiet=true 알림 숨기기 · open=true 끝나면 시뮬 창 띄우기 · return= 결과를 다음 명령으로 넘기기 (예: return=pipe)

이름 · 아이콘 바꾸기 지팡이 메뉴와 팝업 머리에 보이는 "시뮬레이션"이라는 이름과 아이콘을 원하는 것으로 바꿀 수 있습니다. 설정 → 표시 설정.
요청 · 제목 고치기 상세 화면에서 시뮬 요청의 수정으로 요청을 고치면 이후 재생성과 이어쓰기에 반영됩니다. 제목은 연필 버튼으로 바꿉니다.
완료 알림 시뮬이 끝나면 알림과 소리가 납니다. 알림을 누르면 그 시뮬로 바로 갑니다. 끄려면 설정 → 시뮬 완료 시 알림 표시.

05 모아보기와 백업

시뮬은 채팅 파일 안에 저장됩니다. 채팅을 지우기 전이나 기기를 옮길 때는 백업해두세요.

여러 채팅방에 흩어진 시뮬을 한곳에서 보고 싶습니다.

시뮬레이션 모아보기

시뮬이 있는 모든 채팅방을 최근 순으로 보여주고, 방을 눌러 시뮬을 읽을 수 있습니다. 읽기 전용이라, 고치거나 재생성하려면 그 채팅방에 들어가서 여세요. 목록이 실제와 다르면 새로고침, 지운 채팅이 남아 있으면 정리를 누릅니다. 정리는 목록만 정리하고 채팅 파일은 건드리지 않습니다.

찾는 곳설정 → 시뮬레이션 모아보기

시뮬을 파일로 보관하거나 다른 채팅방으로 옮기고 싶습니다.

백업 · 가져오기

이 방 백업은 지금 방의 시뮬을 JSON 파일 하나로 내려받고, 모아보기의 백업은 전체 시뮬을 방별 JSON으로 나눠 zip 하나로 내려받습니다. 가져오기로 이 파일들을 지금 방에 합칠 수 있습니다. zip처럼 방이 여러 개 든 파일은 가져올 방을 하나 고르고, 이미 있는 시뮬은 건너뜁니다.

찾는 곳시뮬 목록 오른쪽 위 ⋮ → 이 방 백업 · 가져오기 · 전체 삭제

실리태번을 켜지 않고 휴대폰에서 시뮬을 읽고 싶습니다.

시뮬레이션 뷰어

백업 JSON을 웹에서 열어 채팅방별로 읽어보는 뷰어입니다. 이어쓰기 파트와 저장된 번역도 함께 보입니다. 지금은 JSON 파일을 하나씩만 열 수 있으니, 전체 백업 zip은 압축을 풀고 방별 파일을 여세요.

열기keepsanity.github.io/simulation-viewer ↗

브랜치 채팅을 열었더니 시뮬이 그대로 있어요. 브랜치는 부모 채팅의 시뮬을 그대로 물려받습니다. 처음 열 때 뜨는 알림을 누르면 브랜치의 시뮬만 비우고, 닫기(×)를 누르면 그대로 둡니다. 어느 쪽이든 부모 채팅은 바뀌지 않습니다.

저장된 프롬프트는 채팅이 아니라 data/<사용자>/user/files/SillyTavern-SimulationManager-saved-prompts.json 에 따로 저장됩니다. 실리태번 데이터를 옮길 때 이 파일도 함께 챙기세요.
